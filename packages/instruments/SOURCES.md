# Instrument wording sources

Fetched 2026-11-01. Wording is copied from the published sources below and is never machine-translated.
`verified` means the text was copied from the named source and checked against it. It does not mean the
translation is clinically validated for any population, and none of these sources prints a validation
statement for the Arabic text. `unverified` rows are shown in the app with a visible label.

The table is kept in step with `src/sources.ts` and the wording data by `test/wording.test.ts`.
